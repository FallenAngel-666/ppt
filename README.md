# EchoNet 3.0 — Interactive Pitch Presentation

An interactive, offline-first 7-slide rotating wheel presentation for **EchoNet 3.0 (Offline Emergency Communication and Evacuation Relay System)**.

## Live Demo & Features
- **Continuous Ambient Slow Spin**: Gentle rotation when idle.
- **On-Click Wheel Snapping**: Rotates smoothly with momentum to the selected topic and adapts the color theme.
- **Ultra-Concise Pitch Format**: 7 high-impact slides covering Problem, Solution, Sub-5ms Edge AI, UN SDGs 2/13, Business Model, and Engineering Mitigations.
- **Editable Team Identity**: Customizable team name input on Slide 1.
